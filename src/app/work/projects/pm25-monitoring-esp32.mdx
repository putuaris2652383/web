## Overview

As a Research Assistant in the IPB University Climatology Lab, I designed and developed an integrated IoT system to monitor PM2.5 dust levels in real time.

## System Architecture

- **Sensor:** DSM501 PM2.5 dust sensor
- **Microcontroller:** ESP32
- **Storage:** microSD module and localhost SQL database
- **Interface:** HTML/PHP-based web interface

## Features

- Real-time PM2.5 monitoring.
- Web dashboard with sorting, download, and visualization options.
- Local SQL data storage for offline access and analysis.

## Skills Applied

IoT prototyping, Arduino IDE, SQL database design, XAMPP/LAMP local server deployment, HTML/CSS/JS dashboard development, serial data parsing, and environmental sensor integration.

## Potential Applications

The system can support community-based air quality monitoring, urban pollution mapping, and citizen-science platforms in under-monitored or high-risk environments.
